# v16 正常完成后交还遥控器（2026-10-19）

按用户要求，当前受监督原地起降测试的正常结束改为人工降落，不自动请求AUTO.LAND。厂家完整高度目标起飞保持，达到车底0.90m并稳定悬停5秒后，程序保持当前位置并请求POSCTL；必须观察到飞控报告POSCTL后才进入PILOT_CONTROL、停止控制目标发布。输出handover_confirmed=true、pilot_landing_required=true，提醒操作者遥控降落；这不意味着已落地或已上锁。

起飞超时或其他仍有可信输入的主动结束路径也请求POSCTL；严重定位/姿态输入故障、RC接管仍保留故障/接管处理，不能在没有本地定位时宣称能够定点。模式请求拒绝或4秒未观察到确认则报错，不重切OFFBOARD、不重解锁、不自动改成AUTO.LAND。飞控自身低电/失联等保护不取消。

此策略仅experiment=takeoff_land可用，mission.pilot_landing_enabled=true。穿框策略没有启用或改动。正常任务完成表示takeoff_hover_completed=true且handover_confirmed=true；它不等价DONE落地。

飞控参数拟单独修改COM_OBL_RC_ACT=4→0：RC在线、Offboard失流且旋翼机本地位置有效时优先POSCTL，供飞手接管；本地定位失效会退化，不能保证锁定位置。正常降落由飞手负责。COM_OBL_ACT、NAV_RCL_ACT、低电等其余参数不改。当前配置期望值必须读回为0才能授权该人工降落入口。此变更由用户“正常任务也让我接管”明确授权，仍需地面未解锁和有效定位条件才执行。

估计器1Hz消息新鲜度修复沿用v15：1.5秒期限，保留真实无效标志锁存并输出明确原因及年龄。当前定位仍因上一轮发散隔离，旧试验配置禁止运动；部署不代表可以直接飞行。

执行件 _diagnostics/prepare_indoor_offboard_policy.py 默认只读；--apply仅在落地未解锁、status=3、A关闭、有效定位和无控制输出时更改上述单项并读回、备份旧参数与配置、禁用旧试验，模板启用人工降落但保持运动禁用。需在现场机械及地面定位恢复、归位后重新绑定预检。没有自动解锁或试飞。

离线测试包括正常完成/超时交还、请求接受不等于已切换、拒绝或确认超时、切换后不再夺回控制、无自动降落/停桨服务请求、飞控期望值不符拒绝，以及继承的起飞和保护测试。不是实飞或SITL验收。
