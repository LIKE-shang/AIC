# v14 厂家方式的目标高度起飞（2026-10-19）

本轮只改原地起飞、悬停、降落，不启用窗框穿越。厂家已验证流程的对照见 _diagnostics/VENDOR_TAKEOFF_COMPARISON_CN.md。复用的是完整高度位置目标和飞控位置环，不启动厂家完整矩形任务，不调用用途未确认的辅助输出，不复制无高度验收的超时推进任务。

配置 mission.takeoff_position_goal_enabled=true、takeoff_vertical_velocity_enabled=false；这两项互斥，且完整目标模式只允许experiment=takeoff_land。开关默认false，必须在本轮配置中明确启用。

PRESTREAM/MODE/ARM阶段保持地面位置目标。只有观察到飞控已解锁、进入TAKEOFF时，才发布(起点X,起点Y,实测地面对应车底0.90m的FCU高度)完整位置目标。使用XYZ位置控制、忽略XYZ速度输入，不再发送固定0.10m/s，也不把参考限在反馈高度前方4cm。全过程保持起始航向目标，30Hz连续输出。

起飞阶段监督分开：横向目标误差超过0.12m仍中止；高于最终FCU目标0.12m仍中止；车身旋转包络、起飞柱、位姿新鲜度与跳变、控制器独占、遥控接管、25秒未达到目标超时、悬停稳定与80cm空中最低点检查保持。爬升期间有意要求的垂直高度差不作为3D跟踪错误。HOVER恢复原来的完整3D误差检查。故障时记录分轴快照及tracking_check=horizontal_and_height_overshoot，避免将目标高度差误读成允许任意漂移。

实际飞控当前MPC_Z_VEL_MAX_UP≈0.40m/s、MPC_ACC_UP_MAX≈0.40m/s²；未写入修改，仅加入参数读回清单和本轮期望值。受监督完整高度试验不接受超出这两个上限的声明。mission.climb_speed_mps=.10保留给旧小步/速度模式，但不限制完整高度位置模式；预检明确显示final_height_position以及实际飞控速度、加速度上限。该上限是配置，不是保证实际速度不超调。

地面坐标必须在本次定位会话重新绑定。保持原起点车头、落地未解锁、急停释放、A关闭。仅操作者在地面预检通过后执行current_takeoff.bash --execute；代理部署及预检不请求解锁。无需手动提前解锁。

测试覆盖完整高度命令只在观察到解锁后发出；带准备延迟和惯性的模拟爬升完成悬停降落；目标相差90cm不会错误拒绝；横向漂移、高度超调、未爬升超时、悬停3D误差仍受控；实际消息掩码保持位置模式；禁止混合模式/穿框复用；参数上限声明缺失或超限拒绝。离线通过不等于实飞或SITL验收。
