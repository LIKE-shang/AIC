# Nano 三环测试分阶段更新包

日期：2026-10-06（Asia/Shanghai）。本包只传递源码，不自动安装、编译或启动节点。

## 范围

- `robot_vision/` 只含三环检测、相关安全模块、独立桥接器/消息、独立 launch、
  安全缺省配置、相机审计/只读回放/标定工具及专用测试/手册。
- 不含任务、飞行演示、相机驱动、PWM 二进制、本机依赖或 Python 缓存。
- 不覆盖窗框脚本、算法或现场参数。三环节点直接导入 `air_target`，
  不依赖 Nano 现有 `vision.py` 是否包含三环 API。
- `build_reference/` 的 CMakeLists.txt/package.xml/setup.py 仅供核对，
  **不是可直接覆盖 Nano 的文件**；其中可能引用 Nano 没有的窗框适配脚本。
- `safety.py` 是共享模块，安装前须比较已有版本，保留现场修改并验证兼容性。
- 硬件通道、开关值、偏轴等仍未确认。场地配置只确认外径、环宽和目标距离，
  所有标定/实际输出允许字段保持拒绝状态。

## 部署顺序

1. 只把压缩包上传到 `/home/abot/`，不在工作空间中直接覆盖解压。
2. 核验包整体 SHA-256，再解压到单独的暂存目录；运行内部 SHA256SUMS 校验。
3. 比较 Nano 现有文件及构建元数据，处理现场差异后仅安装清单范围。
4. 最小合并 OpenSSL、Python 工具安装及 package 依赖，保留原有构建内容。
   新 LaserDecision 与检测器/桥必须一起重建，不能混用旧生成消息。
5. 先运行只读相机审计和离线回放/专用测试，再仅启动 enable_laser=false 的检测器。
6. 标定、接线、物理隔离等现场确认之前，不进入真实激光模式。

包使用 mtime=0，避免 Nano 未设置 RTC 时出现未来时间戳警告。
压缩包/语法/静态隔离测试通过只表示部署产物结构正确，**不是 ROS 构建、
真机视觉或物理命中验收**。
